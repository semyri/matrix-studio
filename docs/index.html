    LET’S CONNECT

    A direct line to your display.

    1. Leave the display plugged into USB for power.
    2. Disconnect it in the old GitHub controller (the X beside its display controls), or close that tab.
    3. Open Matrix Studio as a normal tab in desktop Edge or Chrome.
    4. Choose Connect display, select MI Matrix Display, then choose Pair.
    5. Choose a creation and press Send to display.

    Bluetooth permissions belong to each website. Your browser will ask you to select the device the first time. If it is missing, disconnect other controllers and power-cycle the display.

    Live clocks need this page open. Sending reports Bluetooth writes completed; check the physical display to verify the result.
